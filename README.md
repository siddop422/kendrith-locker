# Kendrith Studios Locker

A beautiful local-first vault for every file your studio makes.

- Drag & drop files/folders
- Categories, search, grid/list views
- ZIP download, rename, preview
- Themes, accents, sound effects
- Everything stored in IndexedDB on the device

## Deploy

This is a single-file static app. Open `index.html` or deploy the folder to Vercel / Netlify / any static host.

**Note:** The full `index.html` from the original Chromaforge.html should be used. Replace the placeholder if needed.

Live temporary preview was deployed via Vercel CLI.
